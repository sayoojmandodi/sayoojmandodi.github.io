About

Grew up on machines. Learned to code after.

I grew up in Kerala with an enthusiasm for building and debugging things, and my college project was where that finally had somewhere to go — a bipedal walking robot, and the night past midnight it first took its steps. That was the moment I understood where my real interest actually was: not the machine alone, but the code that gave it life.

That pulled me toward Renovus in 2017, a small vision-automation startup, where I actually mastered programming — not in a classroom, but shipping code that had to work on a real factory floor. It's where I got confident that nothing in this field is impossible if you sit with a problem long enough, and where giving life to a machine through software — watching a camera finally learn to see — is what made my interest and passion for programming peak. That instinct never left: automate the thing someone has to repeat, so they don't have to.

The systems changed shape after that — automotive embedded, real-time messaging inside a moving car — but the question stayed the same: what can this system catch or do automatically, before someone has to catch it by hand? Eight years in, I'm back in Kerala, still building around that instinct.

Lately that instinct points at LLMs — using them to automate the repeatable parts of engineering itself, like test-case drafting and code review on real-time systems. A GitHub Agentic AI Developer credential made that official this year.
