# Sayooj Mandodi — Portfolio

Personal portfolio site, live at [sayoojmandodi.github.io](https://sayoojmandodi.github.io/).

Single-page static site (HTML/CSS/vanilla JS, no build step, no framework) covering background, skills, work history, and projects across automotive embedded and industrial machine-vision systems.

The "Ask AI" chat panel in the hero is powered by Claude's `sample` capability, which only runs inside a Claude Artifact — on GitHub Pages it gracefully falls back to a static note pointing visitors to the contact form or email instead.
